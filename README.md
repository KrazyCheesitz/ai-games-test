# ai-games-test
a repo filled with ai games ive made using opus 5.5 or other ai models

## Repo layout

Each game lives in its own folder at the repo root. A game folder holds everything for that game:

- the game source
- `README.md`: how to run it, controls, features
- `PROMPT.md`: the prompt used to generate it

A game never changes files in another game's folder.
